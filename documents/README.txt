Both documents are live and linked from documentation.html, privacy-policy.html,
and terms-and-conditions.html.

privacy-policy.pdf and terms-and-conditions.pdf are both 256-bit AES encrypted:
- No password is needed to open, read, print, or download them.
- They CANNOT be edited without the owner password (Nitin has this separately —
  it is intentionally not stored in this repo for security reasons).

If either document's underlying content changes, the source PDF needs to be
regenerated and re-encrypted with the same owner password before replacing the
file here — simply swapping in a new unencrypted PDF will leave it editable by
anyone, defeating the point.
